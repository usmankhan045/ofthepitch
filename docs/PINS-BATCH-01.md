## Before you upload

- [ ] Destination returns 200. Check the date table above.
- [ ] Alt text pasted. This is the only measured lift available: +123%
      outbound clicks (Tailwind 2025, 1.2M pins).
- [ ] Title reads naturally, no template phrasing carried from another pin.
- [ ] Image is 1000x1500.
- [ ] No two pins in the batch share a palette, a crop or a layout.
